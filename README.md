# Z_X Studios website

This is a simple static website for the Z_X Studios Development Team.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `zx-studios-website`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. GitHub will show the exact website URL.

## Important
- The site deliberately states that Z_X Studios is an independent development team, not a registered legal entity.
- LIFE ONLINE is described as under development; planned features are not claimed to be finished.
- No mailing address, personal phone number, or private email is published.
- Do not enter a website URL in Boeing's questionnaire until the site is actually published and publicly accessible. If the questionnaire is due first, write: `Not yet available – official website under development`.
