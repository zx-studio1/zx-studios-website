# Z_X Studios — expanded website

A multi-page, responsive studio website with a new editorial visual identity.

## Included
- `index.html` — homepage
- `studio.html` — team and studio profile
- `project.html` — LIFE ONLINE project overview
- `vision.html` — design principles and public commitments
- `contact.html` — inquiry information
- `assets/css/main.css` — shared responsive design system
- `assets/js/site.js` — language selector and mobile navigation
- `locales/` — English, Arabic, French, Spanish and German translations
- `assets/favicon.svg` — custom vector favicon
- `robots.txt` and `sitemap.xml` — basic site discovery files

## Publish on GitHub Pages
1. Download and extract the ZIP.
2. Open the `zx-studios-website` repository.
3. Upload all files and folders from this package to the repository root.
4. Replace existing files when GitHub asks, then commit the changes.
5. Wait for GitHub Pages to deploy and refresh the site.

Do not upload the ZIP itself as the website. Upload its extracted contents.

## Languages
The language selector supports English, Arabic (right-to-left layout), French, Spanish and German. The homepage and shared navigation are translated. Detailed inner-page copy remains in English in this first multilingual release, so it is not falsely presented as fully translated.

## Accuracy
Z_X Studios is described as an independent development team, not a registered company. LIFE ONLINE is described as an in-development project. Project features are presented as goals/concepts, not completed or playable features. No fake contact details, release dates, approvals or partnerships are claimed.

## Editing
- Add homepage/shared UI translations to each JSON file in `locales/`.
- Add new page content to the relevant HTML page.
- Keep `assets/css/main.css` as the shared stylesheet.
- The language preference is stored in the visitor's browser.
